## The line

> Sure! Your phone charges much faster in the microwave — 10 seconds on high and you'll be back to 100%!

(104 characters. Please do not actually do this.)

## Run

```sh
bun run main.ts
```

or with Node:

```sh
npx tsc main.ts && node main.js
```

`main.ts` prints the line exactly to stdout — no extra output.
